# Section 10 — AI System Design & Interview Preparation

**A compact 2-day, fresher-friendly section.** Each day fits in roughly **1 hour 15 minutes** of teaching.

**No coding capstone.** The goal is job-readiness — the framework to walk into any AI-engineering interview cleanly, plus a portfolio + resume that gets you callbacks.

## Day-by-day

| Day | Topic | Folder |
|-----|-------|--------|
| 1 | **AI system design + RAG at scale + latency/caching** | `Day_1_Design_And_Scale/` |
| 2 | **Interview questions + portfolio, resume & mock walkthrough** | `Day_2_Interview_And_Portfolio/` |

## How each day is organized

Each day folder contains:
- `concepts.ipynb` — 75-min teaching notebook (dense — this is compressed material)
- `main.py` — reference / helper scripts (cost estimator, semantic cache, question prompter, resume checklist)
- `assignments.ipynb` — interview practice, self-review, portfolio building
- `resume_template.md` (Day 2) — copy-paste starting point

## Setup

No new stack. Sections 1–9's environment is enough.

## Prerequisites

- Sections 1–9 completed (you need something to talk about in interviews)
- A GitHub profile — Day 2 turns it into a portfolio

## What you'll walk away with

- The **5-step AI system design framework** you can apply to any prompt
- A **RAG-at-scale reference architecture** with tradeoffs memorized
- Latency + caching playbook: **response / semantic / prompt cache**
- **20 interview questions** with model answers
- A **resume template**, GitHub-pin plan, and a full **mock system-design walkthrough** you can imitate
